# Factory Safety Incident Tracker

The Factory Safety Incident Tracker is a web application designed to digitize safety logging and reporting in a factory environment. It replaces paper/Excel based systems with a digital solution, improving response times and visibility.

## Tech Stack
- **Backend:** Java, Spring Boot
- **Frontend:** Thymeleaf, Bootstrap (HTML5/CSS3)
- **Database:** H2 (development), PostgreSQL (production)
- **CI/CD:** Jenkins
- **Containerization:** Docker
- **Configuration Management:** Ansible
- **Testing:** Selenium, JUnit

## Local Setup
1. Prerequisites:
   - JDK 17 or higher installed.
   - Maven installed.
2. Clone this repository.
3. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```
4. Access the application at `http://localhost:8080`.
